## 优化、标准、国际线路到底差在哪

三条线路的差别在回程路由，不在去程。去程大家都从国内骨干出口出去，差别出现在数据从洛杉矶回中国时走哪条路。

优化线路通常意味着走质量更好的国际中转，代价是端口只给到 20Mbps。国际线路走公共互联网路径，晚高峰容易拥堵，但端口给到 100Mbps，跑满的时候总量更大。

判断方法很简单：如果你的使用场景对延迟敏感（交互式 SSH、远程桌面、实时接口调用），优先优化线路；如果是下载、备份、给海外用户提供内容，优先大端口。

## 原生 IP、住宅 IP、干净 IP 是三件事

搜洛杉矶云服务器的人里，相当一部分是冲着 IP 属性来的。这三个词经常被混着用，实际不是一回事。

**原生 IP** 指 IP 地址的运营商所在国家和服务器地理位置一致。洛杉矶机房配美国运营商归属的 IP，就是原生 IP。**住宅 IP** 指 ISP 分配给家庭或个人用户的地址，来自真实家庭网络，在某些平台上更容易被识别为普通用户。这两个属性在部分商家的套餐列表里会单独标注，比如轻树和朝暮数据的 P 区、P2 区就同时标了原生和住宅。

**"干净 IP""欺诈值"是另一套说法。** 朝暮数据的帮助文档里明确写：某些网站提供的 IP 欺诈值检测并没有评分依据，IP 地址也没有纯净、干净、新老的说法，TikTok 这类公司有自己的 IP 地址库和检测手段。这是服务商自己的立场，属于利益相关方表述，不算行业定论，但它至少说明一件事：花高价买"纯净度评分"之前，先想清楚评分是谁定的。

LightLayer 这边，公开资料只明确提到香港机房的 IP 不是原生 IP，洛杉矶和圣何塞的 IP 属性没有逐机房标注。如果你买洛杉矶是为了流媒体解锁或者平台账号环境，下单前问清楚这一台给的是不是美国本土原生 IP，比看任何评分都直接。
